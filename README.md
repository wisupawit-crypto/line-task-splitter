# LINE Task Splitter

> แปลงแชทกลุ่ม LINE ที่สั่งงานกันมั่ว ๆ ให้กลายเป็นรายการงานของแต่ละคน — แล้วส่งไปหาเจ้าตัวโดยตรง

ปัญหาคลาสสิกของทีมเล็กและร้านค้าไทย: สั่งงานกันในกลุ่ม LINE แล้ว **งานหายไปกับข้อความที่เลื่อนผ่าน** ไม่รู้ใครรับผิดชอบ ไม่รู้เสร็จหรือยัง

โปรเจกต์นี้แก้ปัญหานั้นโดย**ไม่บังคับให้ทีมย้ายไปใช้แอปใหม่** — ยังทำงานในไลน์เหมือนเดิม

## 💡 แนวคิดหลัก: ไฮบริด

ระบบรองรับสองทางพร้อมกัน เพราะแต่ละทางมีจุดอ่อนที่อีกทางอุดได้

### 1. คำสั่ง (ทางหลัก — แม่น 100%)

```
/งาน @ฝน เช็คสต็อกแก้วกับหลอด ก่อนบ่าย 3
/งาน @โบ๊ท @ฝน เติมน้ำเชื่อมให้เต็มทุกขวด ก่อนเปิดร้าน
```

**ทำไมต้องมี `@`** — LINE จะส่ง `userId` ของคนที่ถูก mention มากับ webhook โดยตรง
บอทจึงรู้ทันทีว่าต้อง DM ไปหา account ไหน ไม่ต้องเดาจากชื่อเล่น
(มิ้นท์ / มิ้น / Mint คนเดียวกันไหม?) — ปัญหาที่ AI เก่งแค่ไหนก็แก้ไม่ได้

### 2. บอทสะกิดถาม (ตาข่ายกันตก)

คนลืมใช้คำสั่งคือเรื่องปกติ ระบบจึงคอยดูข้อความที่*น่าจะ*เป็นงานแล้วถามกลับ

> 🤔 นี่เป็นงานของ @ฝน ใช่ไหม? &nbsp; `[ใช่ สร้างเลย]` `[ไม่ใช่]`

กดปุ่มเดียวจบ ได้ความแม่นของคำสั่ง แต่ไม่ปล่อยให้งานหลุดตอนคนลืม
และปุ่มนี้ยังค่อย ๆ สอนให้ทีมชินกับคำสั่งไปในตัว

## 🧠 ตัวแกะงานตอนนี้ (heuristic)

เวอร์ชัน prototype ใช้กฎภาษาไทยแบบง่าย 5 ชั้น:

| ชั้น | ทำอะไร |
|---|---|
| 1 | แยกผู้พูดจาก `ชื่อ: ข้อความ` หรือ LINE export → สร้าง roster |
| 2 | ตัดข้อความตอบรับสั้น ๆ (`ได้ค่ะ`, `รับทราบ`, `โอเค`) |
| 3 | ต้องมีคำกริยาสั่งงาน (~27 คำ: `ช่วย`, `เช็ค`, `สั่ง`, `เติม`, `อย่าลืม` …) |
| 4 | หาคนรับ = ชื่อใน roster ที่ไม่ใช่ผู้พูด เลือกชื่อที่อยู่ต้นประโยคสุด |
| 5 | เดากำหนดเวลาด้วย regex (`ก่อนบ่าย 3`, `10 โมง`, `ตอนปิดร้าน`, `ภายในวันนี้`) |

### ข้อจำกัดที่รู้อยู่

- สั่งงานโดยไม่เอ่ยชื่อ → จับไม่ได้ (`"เดี๋ยวใครว่างช่วยเช็ดกระจกหน่อย"`)
- ใช้สรรพนามแทนชื่อ (`เธอ`, `น้อง`, `คนที่เข้ากะเช้า`)
- ชื่อเล่นเขียนไม่ตรงกับ roster
- หนึ่งข้อความมีหลายงาน → นับเป็นงานเดียว
- คำสั่งที่ไม่มีคำกริยาในลิสต์ → หลุดหมด

➡️ ข้อจำกัดพวกนี้คือเหตุผลที่เวอร์ชันจริงต้องเปลี่ยนไปใช้ LLM ในชั้นที่ 3–5

## ⚠️ ข้อจำกัดของ LINE ที่ต้องรู้ก่อนสร้าง

1. บอทอยู่ในกลุ่มอ่านข้อความได้ แต่จะ **DM หาสมาชิกได้ต่อเมื่อคนนั้นแอดบอทเป็นเพื่อนแล้ว** — ต้องออกแบบ onboarding ให้ดี
2. ต้องใช้ LINE Official Account + Messaging API
3. `@mention` ในกลุ่มจะให้ `userId` จริงมาใน webhook — ใช้ประโยชน์ตรงนี้ให้เต็มที่
